# references/on-page.md — 单页 SEO 深度清单（page 子流程用）

> 按「检查清单 → 判定标准 → 修复方法 → 验证方式」组织。
> 要点提炼自 marketingskills `seo-audit` v2.0.1（2026-09 对照原文核查）。

## 0. 抓取姿势

- 确认最终 URL：先探测跳转链，找到 200 的 canonical 版本再分析（分析 http 版/带参数版没意义）
- 浏览器渲染拿完整 DOM（SPA、JS 注入的 schema/meta 静态抓不到）
- ⚠️ meta description / canonical 可能被 JS 注入或由框架在客户端改写，务必以浏览器渲染后的 DOM 为准

## 1. Title 标签

检查：
- 是否存在且非空
- 全站唯一（同一 title 用在多页 → 稀释）
- 主关键词靠前（前 60 字符内）
- 长度 50-60 字符（Google 显示截断 ~600px；百度 ~30 汉字）
- 品牌词位置（首页可"品牌 - 定位"；内容页可"关键词 | 品牌"，避免浪费字符）
- 无关键词堆砌（塞 3+ 个关键词 → 降权风险）

判定：
- 缺失/空 → 🔴（无标题页基本放弃排名）
- 重复 → 🟠；超长/无关键词 → 🟡

修复：给出替换文案，格式「主关键词 + 价值点 + 品牌（可选）」，控制 50-60 字符。
验证：浏览器标题栏/源码确认；GSC 性能报告看 CTR 变化。

## 2. Meta description

检查：
- 存在且唯一
- 长度 150-160 字符（超出截断）
- 含主关键词 + 点击理由（价值主张/数据/行动号召）
- 与正文一致（不写页面没有的内容 → 高跳出）

判定：缺失 → 🟠（不直接降权但 CTR 吃亏）；重复/截断 → 🟡。
修复：给出替换文案，用「问题/场景 → 解决方案 → 结果/证据」结构。
验证：源码确认；搜索结果页看展示。

## 3. H1 与标题层级

检查：
- H1 恰好 1 个
- H1 含主关键词、描述页面主旨（不是装饰性文案）
- 层级连续：H1 → H2 → H3，不跳级（H1 直接到 H4 是结构缺陷）
- 视觉样式不冒充标题（大号 div 不是 H 标签；反之 H 标签不该用于纯样式）

⚠️ 实战反坑（三站体检实测）：
- 首页 12 个 H1（每个卡片标题都用了 H1）→ 页面主旨稀释，搜索引擎难判断主题 → 🟠
- 页面 0 个 H1-H5（只有 H6 承载"公告/购买"）→ 结构信号缺失 → 🟠
- 博客列表页把每篇文章标题都设 H1 → 应只有页面级一个 H1，文章标题用 H2/H3

判定：>1 个 H1 → 🟠；0 个标题标签 → 🟠；层级跳级 → 🟡。
修复：保留 1 个 H1（品牌标语或页面主标题），其余降级为 H2/H3；按内容语义重排层级。
验证：浏览器 DOM 数 H1 数量 = 1；H2/H3 覆盖子主题。

## 4. 正文与关键词

检查：
- 主关键词在前 100 词内出现（位置信号）
- 自然使用语义相关词（同义词/上下位词，不要机械重复）
- 内容深度匹配搜索意图（信息型给全流程，交易型给对比/价格/评价）
- 首段是清晰定义/答案句（AI 引用 + 精选摘要都爱吃这个结构）
- 内容优于竞争对手（对照 SERP 前 3 评估深度/新鲜度/独特性）
- 内链：指向相关页、锚文本描述性（不用"点击这里"）、每 500-1000 字 1-2 个合理
- 外链：引用的数据/来源链到权威源（E-E-A-T 加分）

判定：关键词 0 次/首段无 → 🟠；内容薄于竞品 → 🟠；锚文本全"点击这里" → 🟡。
修复：重写首段加入定义句；补内容深度；内链用描述性锚文本。
验证：正文检索关键词位置；对照 SERP 前 3 评估。

### 图片优化（独立检查项）
检查清单：
- 文件名描述性（`seo-audit-checklist.png` 而非 `IMG_0231.png`）
- 所有图片有 alt 且描述图片内容（含上下文关键词但不过度）
- 压缩文件体积；现代格式（WebP/AVIF）
- 懒加载（lazy loading）已实现（首屏图除外）
- 响应式图片（srcset/sizes）适配不同视口
- 图片有宽高/尺寸属性（防 CLS）

判定：alt 全空/全重复 → 🟡；未压缩大图 → 🟡（拖 CWV）；纯装饰图 alt 应留空而非硬塞关键词。
修复：批量补 alt、转 WebP、加懒加载。
验证：抽查图片标签；PageSpeed 图片项复测。

## 5. Canonical / schema / 社交标签（单页视角）

- canonical：自引用且与最终 URL 完全一致（含协议与 www）
- schema：类型匹配内容（Article/Product/FAQ…），浏览器渲染确认存在，Rich Results Test 验证
- og:title/og:description/og:image：社交分享卡片（非排名因素，但影响引流 CTR；图片建议 1200×630）
- 图片 SEO：og:image 用绝对 URL

```markdown
- alt 补写：<列表>
```
